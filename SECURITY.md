# Política de seguridad / Security policy

[Español](#español) · [English](#english)

## Español

### Versiones con soporte

Solo la última versión publicada recibe correcciones de seguridad (hoy, la `0.x` más reciente). Si usas una versión anterior, actualiza a la última antes de reportar.

### Cómo reportar una vulnerabilidad

**No abras un issue público.** Usa el reporte privado de GitHub:

1. Entra a la pestaña **Security** del repositorio.
2. Pulsa **Report a vulnerability** (o ve directo a <https://github.com/mundoprogra/json-api/security/advisories/new>).
3. Incluye la versión del paquete, la de PHP y la de Laravel, los pasos para reproducirlo y el impacto que ves.

### Qué esperar

La recepción se confirma en el mismo reporte y ahí mismo se informa del avance. Si la vulnerabilidad se confirma, se corrige y se publica un aviso de seguridad (GitHub Security Advisory) junto con la versión corregida. Se te acredita si así lo deseas.

### Fuera de alcance

Las vulnerabilidades de Laravel, de PHP o de otras dependencias se reportan a sus propios proyectos.

## English

### Supported versions

Only the latest published version receives security fixes (today, the most recent `0.x`). If you use an older version, please upgrade to the latest before reporting.

### How to report a vulnerability

**Do not open a public issue.** Use GitHub's private reporting:

1. Go to the **Security** tab of the repository.
2. Click **Report a vulnerability** (or go straight to <https://github.com/mundoprogra/json-api/security/advisories/new>).
3. Include the package version, the PHP and Laravel versions, the steps to reproduce it and the impact you see.

### What to expect

Receipt is confirmed in the same report, and progress is shared there. If the vulnerability is confirmed, it is fixed and a security advisory (GitHub Security Advisory) is published together with the fixed version. You are credited if you wish.

### Out of scope

Vulnerabilities in Laravel, PHP or other dependencies should be reported to their own projects.
